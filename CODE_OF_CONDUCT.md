# Code of Conduct

VirtFoundry follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

To report violations, contact the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) (**Matheus Thurler**, **Rodrigo Gonçalves**) or the [CNCF Code of Conduct Committee](mailto:conduct@cncf.io).

Do not use public Issues for CoC reports that involve personal safety or sensitive information — email maintainers or `conduct@cncf.io` instead.
