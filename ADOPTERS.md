# Adopters

Organizations and individuals running VirtFoundry in labs or production.

## How to add yourself

1. Fork [virtfoundry/core](https://github.com/virtfoundry/core) (or open an Issue asking a maintainer to add you).
2. Edit this file: add **one new row** at the bottom of the table (keep existing rows).
3. Open a PR titled `docs(adopters): add <your name or org>`.

Homelabs are welcome — traction starts there.
